**Last updated:** 26-10-02 (all review questions resolved; awaiting Julian's diff review and commit)

Julian asked to set up the [Epistemic Memory](https://github.com/FlorianDietz/EpistemicMemory) conventions in this repository, which already had a large root `CLAUDE.md` and a public README for the paper code. Goal: Epistemic Memory becomes the only memory system of the project [decided].

Decisions (verbatim answers and comments in the LOG):

- **Hub file:** `INDEX.md` at the repo root is the agents' hub (team, current status, conversation index), read every session [decided]. `README.md` stays the public, human-facing page of the paper code.
- **CLAUDE.md:** the root `CLAUDE.md` is purely the Epistemic Memory core [decided]. The former root CLAUDE.md lives on as `docs/PROJECT_REFERENCE.md`. We first made it an on-demand reference read before project work. After Julian's review, it became a legacy lookup being phased out: it is not read by default, only consulted for facts the `convos/` files lack, and all its claims are `[assumed]` until checked against the code and recorded in a topic [decided]. The nine subpackage `CLAUDE.md` files are phased out the same way [decided]: renamed to `REFERENCE.md` in their directories (e.g. `spd/harvest/REFERENCE.md`), so Claude Code no longer auto-loads them, with the same legacy `[assumed]` header. Pointers that send readers to the legacy references as an authority (a code docstring, two lines in `docs/CODING.md`) were removed after Julian flagged one [decided]; mentions that describe the phase-out remain. CLAUDE.md now forbids adding or keeping such pointers [decided]. The cluster limit of 8 GPUs stays only in `docs/PROJECT_REFERENCE.md` for now [decided: not important at the moment].
- **Rule conflicts:** template rules win [decided]. The repo's coding guidelines moved into `docs/CODING.md` §Additional instructions without their minimal-comment section; comments follow the template's §Code Comments. These are rules, so they carry no `[assumed]` tag.
- **Layout and git:** template layout at the repo root (`convos/`, `docs/`, `FEEDBACK.md`, `FUTURE_WORK.md`), tracked in git and public on the fork [decided]. Agents never commit or push; Julian reviews the diff and commits [decided]. Agents work on the current branch and do not create their own; they may suggest a different branch only with a concrete benefit [decided: chat request, transcribed in the LOG].
- **Team:** Julian only for now, more may join; folder `convos/julian/` [decided]. INDEX.md states the `git config user.name` matching rule for when others join.
- **Current project goal:** train a tPD of a Qwen model; details to follow in later topics [decided]. Recorded in INDEX.md.
- **Cleanup:** the downloaded template folder `EpistemicMemory-main/` was deleted [decided]. Claude Code's auto-memory for this project holds a single pointer entry redirecting project knowledge to the repo's memory files.
- **Private records:** gitignore patterns added; no private folder created (not requested).
- **Supporting files kept:** FEEDBACK.md and FUTURE_WORK.md stay, because rules in CLAUDE.md and `docs/CODING.md` depend on them [decided]. `docs/HOW_TO_USE.md` and `docs/procedures/multi_agent_debate.md` are kept too [assumed: the agent read Julian's "keep them" as covering these as well].
