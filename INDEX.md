# Targeted Parameter Decomposition — Project Index

This is the agents' hub of the project memory: team, current status, and the index of all discussion topics. Agents read it at the start of every session (see [CLAUDE.md](CLAUDE.md)). The human-facing description of the code is [README.md](README.md).

This repository is Julian Bitterlich's fork (`julxi/targeted-parameter-decomposition`) of Madina Babazhanova's fork (`bbzmdn/targeted-parameter-decomposition`, the `upstream` remote; it added the honesty experiments) of the code accompanying "Targeted Recovery of Weight-Space Mechanisms From Neural Networks" (Vigouroux and Sharkey, 2026; arXiv:2607.13047; original code `Antovigo/targeted-parameter-decomposition`). That paper introduces targeted parameter decomposition (tPD): decomposing only the mechanisms that process a chosen subset of inputs, while a high-rank catch-all `delta` component absorbs everything else. The code is itself a fork of SPD (Stochastic Parameter Decomposition). Coding rules are in [docs/CODING.md](docs/CODING.md). [docs/PROJECT_REFERENCE.md](docs/PROJECT_REFERENCE.md) (the former `CLAUDE.md`: environment, experiments, architecture, commands, cluster rules) is a legacy lookup being phased out; its claims are `[assumed]`.

This project uses the [Epistemic Memory](https://github.com/FlorianDietz/EpistemicMemory) conventions: all project memory lives in LOG/SUMMARY file pairs under `convos/`, governed by [CLAUDE.md](CLAUDE.md). Human guide: [docs/HOW_TO_USE.md](docs/HOW_TO_USE.md). Open ideas and deferred items: [FUTURE_WORK.md](FUTURE_WORK.md). Workflow problems and lessons: [FEEDBACK.md](FEEDBACK.md).

## Current status and goals

Current goal: test whether tPD (targeted parameter decomposition) on Qwen2.5-7B-Instruct recovers truthfulness mechanisms, starting with whether probes on its CI (causal-importance) values detect statement truth beyond baselines [decided: `convos/julian/26-10-02_overview_of_goal_LOG.md`]. See that topic's SUMMARY.

Active branch: `main` (all feature branches are merged into it as of 26-10-02). Current work: targeted decomposition on Truth-is-Universal true/false statements (prepared datasets under `data/tiu/`, three arm configs `spd/experiments/lm/honesty_targeted_decomposition/config_truth_{all_tokens,last_token,padded}.yaml`, which differ only in the training positions). The arm A (all-tokens) experiment is **ended** (26-10-05) [decided: Julian, `convos/julian/26-10-05_no_truth_baseline_LOG.md`]: no evidence that tPD recovers truth-specific mechanisms. CI probes read truth (trained 0.97–0.99) because an untrained CI network already does (0.998). At matched sparsity, trained beats untrained by only 1–2 points, within the run-to-run spread. A code-lines control stayed silent on the statements. Summary: `scratch/arm_A_experiment_summary.md` (gitignored, local); details in `convos/julian/26-10-03_test_accuracy_analysis_SUMMARY.md` and `convos/julian/26-10-05_no_truth_baseline_SUMMARY.md`. The last-token and padded arms were never run. The UTH series (26-10-05) is also **ended** [decided: Julian, `convos/julian/26-10-05_uth_experiments_LOG.md`]: tPD on diverse true/false data from "On the Universal Truthfulness Hyperplane Inside LLMs", tested across task categories. The trained CI values carry no truth information that transfers to unseen tasks (0.488, chance; untrained CI network 0.717; residual stream 0.806). Summary: `scratch/uth_experiment_summary.md` (local); details in `convos/julian/26-10-05_uth_experiments_SUMMARY.md`. Current (26-10-06): analyses of the existing decompositions with `truth_writers.py`: do components write into the truth direction, where is truth written, do different kinds of truth use different writers. tiu and UTH results in; next proposed: ablation controls (`convos/julian/26-10-06_truth_writing_components_SUMMARY.md`). Latest (26-10-14): four tiu decompositions at the statement's period that differ only in what the target loss compares, all trained and analysed (one seed each): the next-token lens (Exp 0) recovers almost none of the verdict-relevant computation, the residual lens (Exp 1) and the appended-question verdict lens (Exp 2) most of it; Exp 3 (verdict lens with the question decomposed) found "True"-writing components at the answer token that follow the model's own judgement, but a cancellation test (26-10-15) showed that the components of every run except partly Exp 1 re-implement the lens output instead of decomposing the MLP outputs (`convos/julian/26-10-10_bolder_experiments_SUMMARY.md`; report `reports/26-10-14_target_lens_experiments.typ`). Newest (26-10-20): steering with Exp 4c's components (4c = tPD of MLPs 11–17 on the statement tokens under a statement-first verdict prompt). A gradient-searched mask over all its components inverts the verdict in some families, but direct-question recall is unchanged, so no belief lever was found (`convos/julian/26-10-16_component_steering_SUMMARY.md`). A self-contained Typst report of the experiments before these: `reports/26-10-06_truth_experiments_state.typ` (PDF gitignored; build with `typst compile`).
